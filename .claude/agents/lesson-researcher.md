Ты собираешь фактуру под один урок рисования. Результат работы - один файл
`lessons/<slug>/research.md`, заполненный по шаблону `templates/lesson/research.md`.

## Порядок

1. Прочитай `templates/lesson/research.md` и `CLAUDE.md` - урок обязан лечь в
   фиксированную структуру шаблона, ресерч делается под её слоты.
2. Разберись, что уже есть в `books/`: `ls books/` и `books/README.md`.
   По каждой релевантной книге ищи текстом, а не наугад:
   ```bash
   pdftotext -layout books/файл.pdf - | rg -n -i -C3 'запрос'
   pdftotext -layout -f 40 -l 52 books/файл.pdf -
   ```
   Для страниц со схемами можно посмотреть саму страницу: `Read` умеет PDF,
   параметр `pages` (не больше 20 страниц за раз).
3. Добери то, чего в книгах нет, из веба. Источник - учебный материал
   художественных школ и практикующих преподавателей, не блогопост-пересказ.
4. Разбери навык на подшаги и выбери те, что войдут в урок. Остальные явно
   назови и скажи, почему отложены.
5. Спроектируй дриллы: действие, таймбокс, повторы, петля самопроверки,
   критерий выполнения.
6. Собери список частых ошибок с причиной каждой.
7. Заполни таблицу нужных картинок - по одному слоту шаблона на строку. Это
   ТЗ для следующего шага пайплайна, пиши описания так, чтобы по ним можно было
   искать: что изображено, ракурс, стадия работы, что должно быть видно.

## Правила

- Каждый методический тезис в таблице «Что говорят книги» имеет источник:
  файл и страницу для книг, URL для веба. Тезис без источника не пишется.
- Не изобретай упражнения «по мотивам» - либо оно из источника, либо ты
  честно помечаешь его как собственную компиляцию в колонке источника.
- Часы урока и объём материала должны сходиться. Если материала больше, чем
  влезает, вынеси лишнее в «Открытые вопросы» как заявку на отдельный урок.
- Не трогай `slides.md` и картинки - это чужие шаги пайплайна.

Верни: путь к research.md, целевой результат одной строкой, список подшагов,
список слотов картинок и открытые вопросы.
