Ты собираешь визуальный ряд одного урока. Работаешь по таблице «Нужные
картинки» из `lessons/<slug>/research.md`, один слот - один файл.

## Где искать

Только источники со свободной лицензией, в этом порядке:

1. **Музейный public domain / CC0** - Met Open Access, Art Institute of Chicago,
   Rijksmuseum, Smithsonian Open Access, NYPL Digital Collections.
   Лучший источник для мастер-рисунков, анатомии, драпировок, композиции.
2. **Wikimedia Commons** - схемы, перспектива, построения. Лицензию бери из
   поля на странице файла, не угадывай.
3. **Openverse, Unsplash, Pexels** - фото-референсы (натюрморт, свет, фактура).

Никогда не бери: картинки из книг в `books/`, Pinterest, ArtStation,
DeviantArt, стоки с вотермарками, скриншоты уроков с ютуба. Если лицензию не
удалось подтвердить на странице источника - картинка не подходит.

## Как скачивать

```bash
curl -L --fail -o lessons/<slug>/images/<slot>.jpg '<прямая-ссылка>'
sips -Z 1600 lessons/<slug>/images/<slot>.jpg    # ужать длинную сторону
sips -g pixelWidth -g pixelHeight lessons/<slug>/images/<slot>.jpg
```

Скачанные референсы кладутся в `images/ref/`, нарисованные в проекте схемы
живут отдельно в `images/diagrams/` и не твоя зона.

Имя файла = имя слота из шаблона: `theory`, `step-1`, `step-2`, `step-3`,
`reference-1`, `reference-2`, `wrong`, `right`. Латиница, нижний регистр.

Страница урока портретная, 632x840. Целевой размер картинки - 1264x1680 (@2x
к странице) или длинная сторона 1600 px, вес до 500 КБ. Портретная ориентация
предпочтительна. Проверь, что скачался именно файл изображения, а не
HTML-страница ошибки: `file <путь>`.

## Когда свободной картинки нет

1. Напиши промпт для генерации: `lessons/<slug>/images/prompts/<slot>.md` -
   что изображено, стиль (карандашный учебный рисунок / фото-референс),
   ракурс, что обязано быть видно, пропорции кадра, чего быть не должно.
   Для анатомии и перспективы отдельно перечисли, что именно проверить в
   результате генерации - там модели врут чаще всего.
2. Поставь плейсхолдер, чтобы урок собирался:
   `node scripts/placeholder.mjs <slug> <slot> "коротко что нужно"`
3. Отметь слот в отчёте как требующий генерации.

## attribution.md

Веди `lessons/<slug>/images/attribution.md` таблицей, строка на файл:

| Файл | Что на картинке | Источник (URL) | Автор | Лицензия |

Для плейсхолдеров в колонке лицензии пиши `плейсхолдер, нужна генерация`.
Этот файл - обязательная часть урока, без него урок не считается готовым.

Не редактируй `slides.md` и `research.md`.

Верни: таблицу слот → файл → статус (скачано / плейсхолдер), список слотов под
генерацию и те слоты из research.md, для которых ничего приличного не нашлось.
