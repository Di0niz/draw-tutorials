# Источники картинок урока 04 «Свет и тон на фигуре»

## Схемы построений (`diagrams/`)

PNG-схемы нарисованы для этого гайда в стиле `templates/illustration-style.md`:
учебный конструктивный рисунок графитом, белый фон, иерархия линий. Это первый
урок курса, где тон обязателен: штрих по форме и один источник слева-сверху.
Ошибочные пластины (`wrong-contour-shading`, `wrong-dark-detail`) намеренно
ломают правило — кайма вдоль контура и деталь темнее тени формы.

| Файл | Что на картинке |
| --- | --- |
| `diagrams/light-direction.png` | Шар и коробка: карта теней в два тона, падающие тени |
| `diagrams/terminator-sphere-box.png` | Мягкий терминатор на шаре, скачок тона на ребре коробки |
| `diagrams/tone-stages.png` | Три стадии одной фигуры: карта теней, падающая тень, рефлекс |
| `diagrams/three-values.png` | Шар: свет, ядро, рефлекс, шкала из трёх ступеней |
| `diagrams/wrong-contour-shading.png` | Ошибка: штрих каймой вдоль контура |
| `diagrams/right-form-shading.png` | Тон по форме, граница внутри диска, рефлекс |
| `diagrams/wrong-dark-detail.png` | Ошибка: деталь на свету темнее собственной тени |
| `diagrams/right-detail-in-shadow.png` | Деталь взята полутоном и подчинена объёму |
