# chest-base

**Где стоит:** страница «Основа: всё лежит на клетке», крупная схема на всю
свободную высоту.

**Что изображено.** Грудная клетка без груди, в двух видах рядом: спереди и
сбоку. Слева фронтальный вид — форма бочки, сужённой кверху, с ключицами
сверху и рёберной дугой снизу; по поверхности идут две дуги, показывающие,
что передняя стенка гнутая, а не плоская. Справа вид сбоку — профиль клетки
с отмеченной передней плоскостью.

**Обязательно видно:**
- клетка сужается кверху, а не книзу;
- передняя поверхность читается гнутой, поперечные дуги провисают вниз;
- нижний край рёберной дуги отмечен, он же нижняя граница области груди;
- в профиль передняя плоскость почти вертикальна, чуть завалена назад;
- вертикаль грудины по центру фронтального вида.

**Чего быть не должно:** груди, сосков, мышц, детальной анатомии рёбер по
одному. Это опора, а не анатомическая таблица.

**Кадр:** горизонтальный, примерно 3:2, два вида в одном кадре.

**Чем заменить:** карандашная пластина в стиле остальных схем урока, либо
пара анатомических таблиц скелета торса в public domain, скадрированная до
грудной клетки. Для фронтального вида годится левая половина
`01-female-silhouette/images/ref/torso-anatomy.jpg`.

**Статус:** `chest-base.svg` — временная векторная заглушка, не в стиле гайда.
Подлежит замене.

**Промпт для отрисовки.** Общий префикс из `templates/illustration-style.md`
плюс:

> back. Line-only study, no shading.
