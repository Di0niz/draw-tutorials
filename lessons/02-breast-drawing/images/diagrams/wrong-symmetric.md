# wrong-symmetric

Пара с `right-varied` для страницы «Ошибка: симметричные близнецы», лейаут
`compare`. Один ракурс и один масштаб в обеих картинках.

**Что изображено.** Торс-манекен анфас, обе массы нарисованы одинаковыми:
правая половина точно зеркалит левую, тот же размер, наклон и высота. По
центру проведена ось симметрии, подчёркивающая механическое отражение.

**Обязательно видно:** обе массы совпадают при отражении; соски / оси на
равном расстоянии от средней линии; ось симметрии читается.

**Чего быть не должно:** намёка на перспективное сокращение. Ошибка именно в
его отсутствии.

**Кадр:** вертикальный, примерно 3:4, одинаковый для пары.

**Статус:** `wrong-symmetric.png` — карандашная пластина в стиле
`templates/illustration-style.md`. Линейный рисунок. Не заглушка.

Замечание: генератор устойчиво выпрямлял разворот в фас, поэтому ошибка
показана как зеркальные близнецы на фронтальном манекене с осью симметрии.
Контраст с `right-varied` (разворот, дальняя масса сокращена) всё равно
читает учебную пару.

**Промпт для отрисовки.** Общий префикс из `templates/illustration-style.md`
плюс:

> Pedagogical MISTAKE plate. Both breast masses drawn as exact mirror images
> of each other, same width, same tilt, same height, with a symmetry axis
> drawn down the centre. Line-only study, no shading, no labels.
