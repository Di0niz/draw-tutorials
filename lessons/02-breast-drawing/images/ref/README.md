# Референсы урока 02

Сюда кладутся найденные изображения под свободной лицензией.

Сейчас в папке:

1. `torso-master.jpg` — William Etty, *Standing female nude*, сангина и мел.
   Met Open Access, public domain. Три четверти: посадка формы на клетке
   читается, годится для дрилла «копия мастера».
2. `pectoral-muscle.jpg` — Gray's Anatomy fig. 410, pectoralis major.
   Public domain. Мужской торс, мелкий кадр (531×650) — как и предупреждала
   таблица в уроке 01.

Ещё нужно, лицензию не выдумываем:

3. `torso-profile-master.jpg` — штудия торса в профиль, чтобы подтвердить
   правило «верхний скат прямее нижнего» на реальном рисунке. Подходящего
   музейного кадра с подтверждённым PD/CC0 в этом заходе не взяли.

Правила те же, что в проекте: только public domain, CC0 или CC BY; лицензия
берётся со страницы источника; длинная сторона 1600 px, вес до 500 КБ; каждая
строка заносится в `attribution.md` рядом. Для CC BY подпись автора обязана
стоять под картинкой в уроке и на странице источников.
