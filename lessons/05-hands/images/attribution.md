# Источники картинок урока 05 «Руки и кисти»

Схемы нарисованы для этого гайда: учебный конструктивный рисунок кисти
графитом по `templates/illustration-style.md`. Ладонь — коробка, пальцы —
веер клиньев, большой — клин от запястья. Внешних референсов в `ref/` нет.

| Файл | Что на картинке |
| --- | --- |
| `diagrams/arm-landmarks.png` | Фигура в 7,5 голов, три отметки: локоть, запястье, кончики пальцев |
| `diagrams/hand-face-measure.png` | Мерка: длина кисти-варежки равна лицу от подбородка до корней волос |
| `diagrams/palm-box.png` | Три вида коробки ладони без пальцев: тыл, ребро, ладонь |
| `diagrams/wrong-flat-palm.png` | Ошибка: ладонь как плоский силуэт без толщины |
| `diagrams/right-box-palm.png` | Верно: ладонь-коробка с торцами и ступенькой запястья |
| `diagrams/thumb-wedge.png` | Клин большого: вид с тыла и вид с торца |
| `diagrams/wrong-thumb-front.png` | Ошибка: большой как пятый палец от костяшки указательного |
| `diagrams/right-thumb-side.png` | Верно: большой растёт от запястья, своя плоскость, перепонка |
| `diagrams/finger-arcs.png` | Три дуги суставов с общим центром; справа ошибка «суставы по прямой» |
| `diagrams/palm-vs-back.png` | Одна кисть с тыла и с ладони: с ладони пальцы короче |
| `diagrams/wrong-sausages.png` | Ошибка: одинаковые пальцы-сосиски, суставы по прямой |
| `diagrams/right-fan.png` | Верно: веер из общего центра, суставы на дугах, разные длины |
| `diagrams/build-stages.png` | Три стадии одной кисти: жест, коробка, веер пальцев |
| `diagrams/gesture-axis.png` | Жест кисти одной осью от предплечья до среднего пальца |
| `diagrams/foreshortening.png` | Кисть в ракурсе, сегменты со ступенькой, ладонь узкой коробкой |

Рядом с каждым PNG — `<имя>.md` с описанием листа и промптом для повторной
отрисовки.
