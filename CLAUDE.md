# draw-tutorials

Курс уроков по рисованию. Метод - освоение навыка за 20 часов (Джош Кауфман,
«Первые 20 часов») плюс принципы из «Мастерства» Роберта Грина. Урок = markdown
для slidev + свои картинки, на выходе PDF.

Язык всего контента - русский. Обращение к ученику на «ты». Термин при первом
упоминании дублируется английским в скобках.

## Структура

```
books/                     PDF-источники, в git не попадают (см. books/README.md)
templates/lesson/          единственный шаблон урока: slides.md + research.md
theme/                     общая slidev-тема: лейауты, компоненты, стили
lessons/<NN-slug>/
  research.md              выход шага 1
  images/                  картинки урока
    attribution.md         источник и лицензия на каждый файл
    prompts/<slot>.md      ТЗ на генерацию там, где свободной картинки нет
  slides.md                урок
  dist/<NN-slug>.pdf       сборка
  shots/                   PNG слайдов для проверки вёрстки
scripts/                   export-pdf, export-shots, placeholder
```

`lessons/00-smoke/` - не урок, а проверка сборки темы. Если тема поехала,
`pnpm shots 00-smoke` покажет это на всех лейаутах сразу.

## Команды

```bash
pnpm dev lessons/<slug>/slides.md   # живой просмотр
pnpm pdf <slug>                     # PDF в lessons/<slug>/dist/
pnpm shots <slug>                   # PNG каждого слайда в lessons/<slug>/shots/
node scripts/placeholder.mjs <slug> <slot> "подпись"   # заглушка под картинку
```

## Пайплайн урока

Четыре шага, каждый - отдельный субагент. Оркестрирует главный агент: он
запускает шаг, показывает результат пользователю и ждёт добро перед следующим.
Шаги не параллелятся - каждый следующий ест выход предыдущего.

| Шаг | Агент | Вход | Выход |
| --- | --- | --- | --- |
| 1. Ресерч | `lesson-researcher` | тема, `books/` | `research.md` |
| 2. Картинки | `image-scout` | таблица картинок из `research.md` | `images/` + `attribution.md` |
| 3. Урок | `lesson-author` | `research.md`, `images/` | `slides.md` |
| 4. PDF | `pdf-builder` | `slides.md` | `dist/<slug>.pdf` |

`drawing-coach` - эксперт по методике, а не шаг конвейера. Вызывается дважды:
после шага 1 (проверить декомпозицию и дриллы, пока ничего не написано) и
после шага 3 (проверить готовый урок). Его вердикт `на доработку` означает
возврат на соответствующий шаг, а не правку «на глазок».

Перед шагом 1 главный агент заводит папку урока:

```bash
mkdir -p lessons/<NN-slug>/images
cp templates/lesson/research.md lessons/<NN-slug>/research.md
```

Slug: номер и короткое имя латиницей, `03-contour-drawing`. Номер задаёт
порядок в курсе.

## Страница и картинки

Страница портретная, 632×840 CSS-пикселей (соотношение 79:105) — под чтение с
телефона и электронной книги, не под проектор. Из этого следуют размеры:

- растровые картинки готовятся в 1264×1680 (@2x к странице) или с длинной
  стороной 1600 px, вес до 500 КБ;
- картинка «на всю страницу» — ровно 1264×1680;
- схемы и построения рисуются в SVG и живут в `images/diagrams/`, найденные
  референсы — в `images/ref/`.

Стиль всех схем задан в `templates/illustration-style.md`: учебный
конструктивный рисунок графитом, иерархия линий, белый фон, один лист — одно
действие. Там же общий префикс промпта для генерации. Новая схема либо сделана
по этому документу, либо прямо помечена как временная заглушка.

Каждая схема лежит парой: файл картинки и рядом `<имя>.md` с описанием рисунка
(что изображено, что обязано быть видно, чего быть не должно, кадр, промпт для
генерации). Описание позволяет заменить схему точечно, не переписывая урок.

Классы для картинок в разметке урока:

- `<div class="fig-tall">` — картинка забирает всю высоту, оставшуюся от текста
  на странице. Для вертикальных схем.
- `<div class="fig-wide">` — то же, но для горизонтальных: ширина по странице.
- `<div class="steps-stack">` — пошаговый разбор: строка = картинка слева,
  что делаем справа.

Вокруг markdown-картинки внутри `<div>` нужны пустые строки, иначе она не
обработается.

## Конвенции урока

- Структура слайдов задана шаблоном и не меняется. Расширять можно только тем,
  что перечислено в `.claude/agents/lesson-author.md`.
- Один урок - один наблюдаемый порог. Не «понимает перспективу», а «строит куб
  в двухточечной перспективе без заваленных вертикалей».
- В каждом дрилле есть таймбокс и петля самопроверки, которую ученик замыкает
  сам.
- Критерии бинарные и измеримые.
- `doneHours` в headmatter - сумма часов предыдущих уроков курса, чтобы полоса
  прогресса к 20 часам была сквозной.
- Заметки преподавателя живут в `<!-- -->` в конце слайда и в PDF не попадают.

## Картинки и лицензии

- В уроки идут только изображения со свободной лицензией. Источник, автор и
  лицензия записываются в `images/attribution.md` - без этого урок не готов.
- Иллюстрации из книг в `books/` в уроки не попадают. Из книг берём текст и
  методику.
- Где свободной картинки нет: промпт в `images/prompts/<slot>.md` плюс
  плейсхолдер, чтобы урок собирался. Такие слоты перечисляются в отчёте о
  готовности урока.

## Чего не делать

- Не править `theme/` в ходе работы над уроком. Тема общая: изменение ломает
  все собранные уроки. Это отдельная задача, и проверяется она на `00-smoke`.
- Не коммитить `dist/`, `shots/`, `node_modules/` и PDF книг.
- Не выдумывать методику мимо источников. Тезис без ссылки на книгу или
  учебный материал в урок не идёт.
