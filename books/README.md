# Книги-источники

Клади сюда PDF. Файлы не коммитятся (`.gitignore`), в репозитории живёт только этот список.

Именование: `автор-краткое-название.pdf`, латиницей, в нижнем регистре.
Пример: `kaufman-first-20-hours.pdf`.

## Каталог

| Файл | Автор, название | Роль в уроках |
| --- | --- | --- |
| `kaufman-first-20-hours.pdf` | Джош Кауфман, «Первые 20 часов» | метод: декомпозиция навыка, таймбоксы, критерии |
| `greene-mastery.pdf` | Роберт Грин, «Мастерство» | врезки «Совет мастера» |
| | | |

Как читать в агенте:

```bash
pdftotext -layout books/файл.pdf - | rg -n -i 'запрос'   # поиск по тексту
pdftotext -layout -f 40 -l 52 books/файл.pdf -           # страницы 40-52
pdfimages -list books/файл.pdf | head                    # что за картинки внутри
```

Иллюстрации из книг защищены авторским правом. В уроки они не попадают:
из книг берём только текст и методику, картинки ищем под свободной лицензией
(см. `.claude/agents/image-scout.md`).
